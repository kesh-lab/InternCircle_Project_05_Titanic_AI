# Titanic AI - Survival Prediction System

An interactive Machine Learning application that predicts
the survival probability of Titanic passengers.

## Features
- Passenger class selection
- Gender selection
- Age and ticket fare inputs
- Survival prediction
- Estimated survival probability

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Machine Learning Model
Decision Tree Classifier

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer
Predictions are estimates based on historical Titanic data
and are intended for educational purposes.
